# CRM Infra Monorepo — ИТ-инфраструктура офиса CRM-компании (РФ)

Проектирование и подготовка к развёртыванию ИТ-инфраструктуры офиса на 300–500 человек (5 этажей, разработчик CRM для заводов, саппорт 24/7, РФ, 2026).

## Как читать

1. `PLAN.md` — план работ и открытые вопросы к бизнесу
2. `docs/00-requirements.md` — что попросил бизнес (со всеми уточнениями)
3. `docs/01-architecture.md` — целевая картина + ключевые решения
4. Дальше по доменам:
   - `docs/02-server-room.md` — серверная: помещение, холод, АУПТ
   - `docs/03-network.md` — сеть: ядро, доступ, периметр, Wi-Fi, VLAN-план, вердикт по старому железу
   - `docs/04-compute-storage.md` — серверы, HCI/Ceph, Proxmox, бэкапы
   - `docs/05-workplaces.md` — парк рабочих мест и стратегия ОС
   - `docs/06-telephony.md` — телефония и колл-центр 24/7
   - `docs/07-power.md` — ИБП, ДГУ, бесперебойность
   - `docs/08-security-compliance.md` — 152-ФЗ, госконтур, СЗИ, 1С
   - `docs/09-software-stack.md` — каталог, почта, файлы, мониторинг, IaC-стек
5. Закупки и внедрение:
   - `docs/10-procurement.md` — спеки и два бюджета (эконом ~63–75 млн / полный ~115–135 млн, оценки)
   - `docs/11-rollout.md` — поэтапный план внедрения
   - `docs/12-meeting-defense.md` — шпаргалка для защиты на совещании

## research/

Сырые исследования с источниками (54+ URL): железо, EoL-статусы, законы, прайсы. Все цены в документах — оценки из этих источников; перед закупкой запрашивать КП.

## iac/

Каркас под Infrastructure-as-Code (Ansible, OpenTofu). Код появится на этапе внедрения (см. `docs/11-rollout.md`), структура уже определена.

## Принципы проекта

- Админ ИТ один → максимальная автоматизация, унификация, ЗИП
- Санкционная устойчивость: решения должны жить в РФ без зарубежных подписок
- Всё как код и документация в git: «как построено» = «как задокументировано»
