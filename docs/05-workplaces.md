# 05. Рабочие места: железо, ОС, жизненный цикл парка

> Детали и источники: `research/w2-workplaces.md`

## Решение (кратко)

- **Форм-фактор:** mini-PC для всех десктопов (офис, бухгалтерия, колл-центр); tower только части разработчиков; моноблоки не закупаем; выездным — ноутбуки.
- **Унификация:** 2–3 аппаратные модели на весь парк → 2–3 образа, ЗИП 5–8% для «горячей замены за 15 минут» (главный механизм SLA при одном админе).
- **ОС:** гибрид ~80/20 в пользу Linux (РЕД ОС / Astra). Windows 11 — только бухгалтерия и выездные интеграторы.
- **VDI:** не внедряем на текущем масштабе (не окупается до 150+ однотипных мест).
- **Автоматизация парка:** GLPI + FOG + Ansible-pull + локальный WSUS — бесплатный стек, ~4–6 недель внедрения.

## Матрица парка (расчёт на 400 мест, масштабировать пропорционально)

| Роль | Кол-во | Устройство | Конфиг | Цена/место (оценка) |
|---|---|---|---|---|
| Офис (продажи, аналитики, PM) | 190 | Mini-PC: Lenovo ThinkCentre M70q/M75q Tiny (полный) / iRU, Kraftway mini (эконом) | i5/Ryzen 5, 16 ГБ, 512 NVMe | 38–70 тыс. + монитор 24" |
| Бухгалтерия | 30 | Та же модель + второй монитор | 16 ГБ, 512 ГБ | +12–20 тыс. |
| Разработчики/QA | 80 | Minisforum UM790 Pro / ThinkCentre 32 ГБ / tower Kraftway | 32–64 ГБ, 1 ТБ | 75–130 тыс. |
| Выездные интеграторы | 40 | Ноутбук: Huawei MateBook D16 (официальная гарантия в РФ) / ThinkPad E14 Gen 6 (парал. импорт) | 16 ГБ, 512 ГБ | 80–100 тыс. |
| Колл-центр 24/7 | 60 | Младший mini-PC (Beelink N100 / iRU) + USB-гарнитура | 8–16 ГБ | 25–45 тыс. + гарнитура |

**Почему mini-PC:** дёшев по железу и электричеству (15–35 Вт), VESA-крепление за монитор, при отказе меняется целиком за 15 минут из ЗИП — при одном админе это важнее апгрейдабельности.

**Ноутбуки для выездных:** Huawei/Honor — единственные с настоящей официальной гарантией и сервисом в РФ (критично: интегратор ломается в поле на заводе). ThinkPad — параллельный импорт с расширенной гарантией продавца (DNS/Ситилинк).

## Стратегия ОС — реалистичный гибрид

**Правовое поле Windows 2026:** корпоративные соглашения Microsoft не продлеваются; бессрочные лицензии, купленные ранее, легальны; новые ключи — только «серый» канал (реэкспорт), юридическая чистота под вопросом. Windows 10 EOL 14.10.2025 — парка на нём быть не должно.

| Роль | ОС | Почему |
|---|---|---|
| Бухгалтерия (30) | **Windows 11 Pro** | 1С тяжёлые конфигурации, банк-клиенты, КриптоПро, печати — минимум риска. Пилот Linux-клиента 1С в 2026, переход 50% в 2027 |
| Продажи/аналитики/PM (190) | **РЕД ОС 8 / Astra Linux** + Р7-Офис | CRM — веб, почта — веб. Миграция безболезненна |
| Разработчики/QA (80) | Linux (Astra/ALT/РЕД/Ubuntu LTS) | Нативная среда разработки |
| Интеграторы (40) | **Windows 11 Pro** | Выезды на заводы: SCADA-клиенты, драйверы, специфический софт заказчика |
| Колл-центр (60) | **Linux-киоск** | РМ = браузер (CRM) + софтфон. Идеальный кандидат; образ восстанавливается за 10 минут через FOG |

Итог: **~70 мест Windows (17%), ~330 Linux (83%)** — экономия ~10–15 млн ₽ на лицензиях + легальная чистота.

**Проверено по совместимости:** 1С 8.3 нативно работает на Astra/РЕД/ALT (в т.ч. с PostgreSQL); КриптоПро CSP 5.0 — под Linux; СберБизнес — официально на Linux. Риск: старые «толстые» банк-клиенты отдельных банков — проверить конкретный банк бухгалтерии до миграции.

**Офисный пакет:** Р7-Офис (~3 тыс./польз./год) или МойОфис (~6,7 тыс./год) — работают на обеих ОС.

## Автоматизация жизненного цикла (один админ!)

Стек (бесплатный): `GLPI (инвентарь+helpdesk) + FOG (образы, PXE) + Ansible-pull (Linux-конфиги из Git) + MDT/WDS + локальный WSUS (Windows) + локальные зеркала репозиториев + Zabbix`.

- Linux-машины: PXE → preseed → Ansible-pull из монорепы — нулевая инфраструктура управления, конфигурация подтягивается сама.
- Windows (70 мест): MDT+WDS, образ на модель, KMS/MAK. WSUS работает локально (deprecated, но обновления ОС публикуются).
- Инвентаризация и заявки: GLPI + агент. Учёт выдачи (ноутбуки, гарнитуры): Snipe-IT.
- Эталонные образы пересобираются раз в квартал; ЗИП-машины пролиты заранее.

После внедрения поддержка парка 400 мест ≈ 30–40% времени админа.

## Почему не VDI

60 мест колл-центра на VDI (Termidesk): ~5–6 млн ₽ (серверы + лицензии + тонкие клиенты) против ~2,5 млн ₽ за mini-PC + Linux-киоск, плюс единая точка отказа и нагрузка на админа. Пересматривать при росте КЦ >150 мест или требованиях ИБ «ноль данных на АРМ».

## Бюджеты (400 мест, оценка)

- **Эконом ~30 млн ₽ (~73 тыс./место):** отечественное железо (iRU/Kraftway/Digma/Beelink), РЕД ОС + «серые» ключи Windows на 70 мест.
- **Оптимум ~45–49 млн ₽ (~115 тыс./место):** Lenovo ThinkCentre Tiny (единая платформа, один образ на 280 мест), Huawei-ноутбуки, Astra Linux (или РЕД ОС → ~45 млн), МойОфис.

## Ответ на «почему так дорого»

Стоимость места 73–115 тыс. ₽ — это железо + монитор + ОС + офисный пакет, разово на 4–5 лет. Альтернатива «все на Windows как раньше» стоит +10–15 млн ₽ на лицензиях и юридический риск. Гибрид — это не экономия на пользователях, а легализация парка.
