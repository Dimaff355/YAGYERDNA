# 09. Софт-стек инфраструктуры

> Частично: `research/` (волна 2, лейн софт-стека — доработан оркестратором). Источники: см. research-файлы + serverzilla.ru, secradar.ru, habr.com.

## Решение (кратко)

| Домен | Выбор | Почему |
|---|---|---|
| Каталог/домен | **ALD Pro** (Astra, на FreeIPA) + **Keycloak** для SSO веб-сервисов | MS AD в РФ 2026 не покупается легально; ALD Pro — реестр, совместим с Windows-клиентами, миграция с AD; ~1,5–3 тыс./польз./год |
| Почта (400 ящиков) | **VK WorkSpace** или **Яндекс 360** (облако РФ) | Почта — последнее, что стоит держать on-prem одному админу: антиспам, репутация IP, DKIM/SPF, резервный MX. ~1,7–2,4 млн ₽/год на 400 ящиков |
| Файлы/«помойка» | **Nextcloud** + OnlyOffice; Samba-шары как fallback | Стандарт де-факто, LDAP/OIDC, мобильные клиенты; СУБД PostgreSQL + Redis + S3-бэкенд |
| Документооборот | Nextcloud + workflow в helpdesk на старте; при запросе бизнеса — ELMA365 / Directum RX | «Какой — не важно» (с) бизнес |
| Мониторинг | **Zabbix** (+ Grafana для красивых дашбордов) | Один админ: агенты, SNMP, шаблоны, алерты в Telegram из коробки; Prometheus — для dev/метрик приложений, по желанию разработки |
| Бэкапы | **Proxmox Backup Server** + вторая копия в S3 (Yandex/VK Cloud) | 3-2-1, бесплатно, интегрирован с Proxmox. Veeam в РФ 2026 — лицензии через третьи руки, без обновлений; российские аналоги (Кибер Бэкап, RuBackup) — если потребует реестр |
| Git / CI | **GitLab CE self-hosted** (работает в РФ, ставится с зеркал) или **GitFlic/Gitea** | GitLab CE — привычен разработчикам; GitFlic — российский, если политика потребует |
| Helpdesk / ITAM | **GLPI** + агент (+ Snipe-IT для учёта имущества) | Бесплатно, инвентаризация + заявки; см. `05-workplaces.md` |
| Ansible-управление | **Ansible + AWX** | Декларативная конфигурация всего: ВМ, сетевые железки, рабочие места Linux (Ansible-pull) |
| IaC | **Ansible** (основа) + **OpenTofu** (форк Terraform; в РФ реестр провайдеров HashiCorp заблокирован — зеркала Yandex Cloud) + **OpenBao** (форк Vault) для секретов | Terraform/Vault после ухода HashiCorp из РФ — юридически серые; OpenTofu/OpenBao — открытые форки |
| Парольный менеджер команды | Vaultwarden (self-hosted Bitwarden) | Один админ ≠ пароли в голове |

## Ключевые обоснования

**Почему не MS AD:** Windows Server легально не купить в РФ 2026; строить домен на серых лицензиях — закладывать аудит-риск в фундамент. ALD Pro: реестр Минцифры, GPO-аналог (Policy Manager), совместимость с Windows 11-клиентами (70 мест из `05`), миграция при необходимости. Для Linux-мажоритарного парка это ещё и естественнее.

**Почему почта в облаке, а не self-hosted:** Mailcow/iRedMail для 400 ящиков — это постоянная работа: rspamd-тюнинг, репутация IP, PTR, блок-листы, резервный MX. Один админ не должен быть почтмейстером. VK WorkSpace/Яндекс 360: SLA, ПДн в РФ (152-ФЗ ок), мобильные клиенты. Стоимость сопоставима со стоимостью времени админа.

**Почему PBS, а не Veeam:** Veeam ушёл из РФ; покупка через третьи руки без обновлений безопасности — для системы бэкапов, имеющей доступ ко ВСЕМ данным, это неприемлемый риск. PBS бесплатен, дедупликация, верификация бэкапов, tape/S3-экспорт. Второй слой: критичные БД и документы → S3 (Yandex Cloud / VK Cloud) — 3-2-1 с «одной копией вне здания».

**Мониторинг:** Zabbix — единая точка: серверы (агент), сетевое (SNMP), ИБП (SNMP), NetPing (среда), МikoPBX, SLА-метрики. Алерты → Telegram-группа дежурных. Grafana — поверх для дашбордов руководству («красивые картинки для гендира» — бесплатно).

## Размещение

Всё вышеперечисленное — ВМ на инфра-кластере Proxmox (см. `04-compute-storage.md`): суммарно ~15–20 ВМ инфраструктурных сервисов, HA через кластер.
