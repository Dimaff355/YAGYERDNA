# 06. Телефония и колл-центр 24/7

> Детали и источники: `research/w1-wifi-telephony-power.md`

## Решение (кратко)

- **Платформа:** MikoPBX on-prem (Asterisk, русская веб-морда, бесплатная база) в HA-паре ВМ на инфра-кластере + **облачный резерв у МТТ/UIS** (переадресация 8-800 при падении здания/канала).
- **SIP:** два независимых оператора (МТТ + Ростелеком) с автопереключением транков.
- **Железо:** колл-центр — софтфоны + USB-гарнитуры; офис — Fanvil/Yealink; руководителям — Yealink T43U/T46U.
- **Рост:** при >50 операторах и потребности в dialer/WFM — колл-центр мигрирует на Oktell, MikoPBX остаётся транковой АТС.

## Почему MikoPBX, а не 3CX / не ВАТС целиком

- **3CX:** ушла из РФ; лицензии продаются через «партнёров», активация — обходные схемы, риск отключения в любой момент. Для колл-центра 24/7 закладываться на это нельзя.
- **Чистая ВАТС (МТТ/UIS) для всего:** ~500–1500 ₽/сотрудник/мес → на 400 абонентов ~0,6–1,8 млн ₽/год навсегда + зависимость от облака. Дорого и не нужно.
- **MikoPBX:** бесплатное ядро, русский UI, маркетплейс модулей, платная поддержка от ~100 тыс./год. AMI/ARI + REST — **идеальная интеграция с самописной CRM**: карточка клиента по звонку, click-to-call, записи разговоров ссылкой в CRM. Для компании, которая сама пишет CRM, это стратегически правильно: телефония — часть продукта, а не чёрный ящик подрядчика.
- Посильно одному админу: веб-морда, бэкапы в один клик, бесплатная база знаний на русском.

## Отказоустойчивость телефонии (критично: саппорт 24/7)

1. Две ВМ MikoPBX (основная + горячий резерв на другой ноде кластера), репликация конфига, ежедневные бэкапы.
2. Два SIP-оператора, автопереключение транков.
3. Облачный профиль у МТТ/UIS: при полной потере здания — переадресация 8-800 на облачные номера операторов (сценарий «здание сгорело, саппорт работает с ноутбуков»).
4. VLAN VOICE с QoS (EF), приоритет голоса на этажных свитчах.
5. Этажные шкафы и серверная на ИБП + ДГУ (см. `07-power.md`) — телефония не должна умирать раньше людей.

## Закупка

| Позиция | Эконом | Полный |
|---|---|---|
| Платформа | MikoPBX (0 ₽) + модули колл-центра/CRM ~50–100 тыс. + поддержка 1 год ~100 тыс. | то же + Oktell для КЦ (внедрение ~200–400 тыс. + 40–80 тыс./мес) |
| Телефоны офиса (~200 шт) | Fanvil X3SG/X5U ~8–14 тыс./шт ≈ 1,6–2,0 млн (или софтфоны = 0 ₽) | Yealink T43U/T46U ~12–24 тыс./шт ≈ 2,4–4,8 млн |
| Гарнитуры КЦ (30–50 шт) | Logitech H390 / Yealink UH36 ~3–7 тыс./шт | Jabra Evolve / Poly Blackwire ~5–10 тыс./шт |
| SIP-транки | 2 оператора ≈ 15–40 тыс./мес | то же |

- Заложить **замену 20–30% гарнитур в год** (износ 24/7).
- Cisco-телефоны (CP-78xx/88xx) не брать: параллельный импорт, без обновлений.
- Eltex VP-15/17 — если понадобится реестр Минпромторга для госконтура.
