# Софт-стек и серверная для офиса 300–500 человек (РФ, 2026)

> Контекст: CRM-разработчик, 1 системный администратор. Приоритет — автоматизация и простота эксплуатации, self-hosted, РФ-реалии 2026.
> Черновик, разделы дополняются по мере исследования.

## A. Софт-стек инфраструктуры

### A.1 Каталог и SSO

**Расклад в РФ 2026:**
- **MS Active Directory** — лицензии Windows Server 2022/2025 в РФ купить официально нельзя (Microsoft ушёл, продление соглашений закрыто). Остаточные/серые лицензии работают, но это юридический и аудит-риск; новые компании AD не строят. Оставлять AD имеет смысл только если он уже есть и есть «вечные» лицензии.
- **ALD Pro (Astra Group)** — де-факто стандарт импортозамещения: основан на FreeIPA, домен совместим с Windows-клиентами (GPO через свои инструменты + ALD Pro Policy Manager), в реестре Минцифры, есть миграция с MS AD. Для компании 300–500 чел. с Windows-парком — основной кандидат. Лицензии: подписка на пользователя/устройство, ориентировочно ~1,5–3 тыс. ₽/польз./год (зависит от редакции).
- **FreeIPA (vanilla) / Samba-AD** — бесплатно, но: FreeIPA требует ручной сборки GPO-эквивалента (Ansible/скрипты), Samba-AD эмулирует AD, но зрелость ниже. Для одного админа самопал без вендорской поддержки — риск.
- **РЕД АДМ (РЕД СОФТ)** — конкурент ALD Pro, тоже на FreeIPA, но по отзывам сообщества (Хабр, K2Tech) беднее по автоматизации и инструментам миграции. Берут в основном там, где уже стек РЕД ОС.

**Рекомендация:** **ALD Pro** как домен/каталог + Keycloak (self-hosted, OSS) как SSO/OIDC для внутренних веб-сервисов (GitLab, Grafana, Nextcloud, GLPI — все умеют OIDC/LDAP). Связка покрывает и Windows-логины, и единый вход в веб.

### A.2 Почта (300–500 ящиков)

- **Exchange on-prem** — не реалистично в РФ 2026: лицензий нет, обновлений безопасности нет, Exchange стал мишенью №1 (ProxyLogon/ProxyShell-эпоха). Избегать.
- **Облачные РФ-сервисы (реалистичный выбор для 1 админа):**
  - **VK WorkSpace (VK WorkMail)** — почта + мессенджер + диск + календарь, от ~350–500 ₽/польз./мес по тарифам; для 400 ящиков ≈ 1,7–2,4 млн ₽/год.
  - **RuPost** — почта/календарь, серверы в РФ, тарифы сопоставимы (~300–450 ₽/польз./мес).
  - **Яндекс 360 для бизнеса** — от ~299–450 ₽/польз./мес, зрелый веб/мобильный клиент, ПДн-хранение в РФ.
- **Self-hosted Mailcow / iRedMail** — бесплатно (Mailcow ~ Docker-стек Postfix+Dovecot+SOGo), но для 400 ящиков это: антиспам (rspamd), репутация IP, PTR/DKIM/SPF, кворум с провайдерами, резервный MX, архив — полноценная нагрузка на одного админа. Реалистично только при сильной мотивации держать почту в контуре (и то лучше с внешним антиспам-шлюзом).

**Рекомендация:** облако VK WorkSpace или Яндекс 360 (почта — последнее, что стоит держать on-prem одному админу); self-hosted Mailcow — только если политика требует контур.

### A.3 Файловое хранилище и СЭД

- **Nextcloud** — стандарт де-факто: файлы, WebDAV, шаринг по ссылкам, интеграция LDAP/OIDC, OnlyOffice/Collabora для совместного редактирования, мобильные клиенты. Тяжелее Seafile, но экосистема богаче. Для 300–500 пользователей — норм при нормальной СУБД (PostgreSQL) + Redis + S3-бэкенде.
- **Seafile** — быстрее на синхронизации большого числа мелких файлов, дедупликация блоками; экосистема и интеграции беднее. Хорош как «сетевой диск».
- **Samba-шары** — минимум для «проводника» и legacy-скриптов; держать рядом как fallback, не как основную платформу.
- **СЭД (кратко — «какой, не важно»):** коммерческие — ELMA365, Directum RX (оба в реестре, коробочные/облачные, от ~1,5–3 тыс. ₽/польз./мес в облаке); open-source — по сути нет зрелых РФ-альтернатив, ближайшее — Alfresco Community (требует пиления). Если СЭД не критичен — Nextcloud + workflow в helpdesk закрывает 80% потребностей.

**Рекомендация:** Nextcloud (+ OnlyOffice Docs) на VM, данные на NFS/S3; Samba-шары оставить для совместимости.
