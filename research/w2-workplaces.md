# Стратегия рабочих мест для офиса 300–500 человек в РФ (2026)

**Контекст:** CRM-компания для заводов, один ИТ-админ, приоритет — максимальная автоматизация развёртывания и обслуживания. Расчёт приведён для усреднённого штата **400 человек**: офисные роли 220 (бухгалтерия 30, продажи 120, аналитики 40, PM 30), разработка/QA 80, выездные интеграторы 40 (ноутбуки), колл-центр 24/7 — 60 рабочих мест.

Все цены — **оценка** (₽, конец 2025 — начало 2026, ритейл/корпоративные поставки РФ).

## 1. Парки устройств по ролям

### 1.1. Выбор форм-фактора

| Форм-фактор | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **Mini-PC (NUC-аналоги, ~1 л)** | Дёшев в закупке и по электричеству (15–35 Вт), крепление VESA за монитором, быстрая замена «целиком» при отказе (важно при 1 админе), тихий | Ограниченный апгрейд (2×SO-DIMM + 1–2 M.2), у китайских брендов слабый сервис | **Основной форм-фактор для всех десктопных ролей** |
| **Tower/SFF** | Апгрейд, дискретная GPU, дешевле в ремонте | Занимает место, шум, выше TCO | Только для части разработчиков/QA (нужна GPU/много RAM) |
| **Моноблок** | Эстетика, меньше кабелей | При отказе БП/матрицы — в ремонт всё устройство; нагрев; сложнее образ (модели разъезжаются) | Не рекомендуется для массового парка; допустим для ресепшн/переговорок |

**Принцип при одном админе:** унификация. 2–3 аппаратные модели на весь парк → 2–3 образа, одинаковые драйверы, ЗИП из 5–10% устройств для «горячей» замены.

## 2. Стратегия ОС

### 2.1. Windows/Office в РФ 2026 — правовое поле

- Microsoft с 2022–2023 прекратила прямые продажи и продление корпоративных подписок (M365 и др.) для российских юрлиц; VLSC-объёмные соглашения не продлеваются. Источники: РБК, comss.ru, allsoft.
- **Бессрочные лицензии, купленные до ухода, остаются действующими** — их использование законно.
- Новые «коробочные»/OEM-ключи Windows 11 Pro и Office LTSC продаются ритейлерами (allsoft, Softline, DNS, маркетплейсы) по **12 000–25 000 ₽** за Windows 11 Pro и **25 000–45 000 ₽** за Office LTSC 2024 — это «серый» канал (реэкспорт лицензий других регионов). Прямой уголовно-правовой ответственности за использование нет, но **юридическая чистота для средней/крупной компании под вопросом**; при проверках (ФНС совместно с правообладателем ранее, налоговые «серые схемы») — риск признания лицензии недействительной. Софт параллельным импортом легализован НЕ был (постановление касается товаров, ПО лицензируется договором).
- **Windows 10 EOL — 14.10.2025.** Парка на Win10 в 2026 быть не должно.
- Практика рынка 2025–2026: коммерческие компании либо (а) докупают «серые» ключи и берут риск, либо (б) уводят максимум рабочих мест на отечественные ОС, оставляя Windows там, где без неё нельзя.

## 3. Автоматизация жизненного цикла при одном админе

### 3.1. Развёртывание образов

- **Windows (70 мест)**: **MDT + WDS** на Windows Server — бесплатно, работает в РФ (всё локально, активация KMS на своём сервере либо MAK-ключи). Один эталонный образ на модель + Unattend + драйвер-паки по моделям (DriverGroup). Альтернатива без Windows Server: **FOG** (PXE, multicast, захват/развёртывание образов Windows через sysprep — работает).
- **Linux (330 мест)**: **FOG** (образ на каждую аппаратную модель) или лучше — **установка по PXE + post-install через Ansible**: кикстарт/preseed → Ansible-pull (playbook роли: офис / колл-центр / разработчик). Ansible-pull с Git-репозиторием = нулевая инфраструктура управления, машины сами подтягивают конфигурацию.
- Практика: эталонные образы пересобирать раз в квартал (или пайплайном), ЗИП-машины держать пролитые.

### 3.2. Инвентаризация / ITAM / Helpdesk

- **GLPI 10/11 + GLPI Agent** (бесплатно): автоинвентаризация (агент раскатывается через GPO/Ansible), сетевое обнаружение SNMP, учёт лицензий, заявки пользователей — закрывает 90% потребностей. Де-факто стандарт самописного ITSM в РФ.
- **Snipe-IT** — учёт имущества/выдачи (ноутбуки интеграторам, гарнитуры), QR-инвентаризация. Ставится рядом с GLPI или вместо его ITAM-части.
- Российские альтернативы (если нужен вендор и реестр): **АйТи-Инвентарь**, **SimpleOne ITAM**, Naumen — от сотен тысяч ₽/год; при одном админе и 400 мест — GLPI рациональнее.

### 3.3. Патч-менеджмент

- **Windows**: локальный **WSUS продолжает работать** — Microsoft объявил его deprecated (не развивается, в Server 2025 только сохранение функциональности; с апреля 2025 прекращена синхронизация *драйверов*, обновления ОС продолжают публиковаться). Для парка в 70 Windows-машин WSUS на той же ВМ, что и MDT — рабочий и проверенный вариант; управление через GPO, автоодобрение критических. Перспективная замена при росте — сторонние агентские решения или перенос Windows-парка на Linux (см. стратегию).
- **Linux**: локальное зеркало репозиториев (apt-mirror / reposync+crep для РЕД ОС) на 50–100 ГБ; точечное одобрение пакетов через Ansible; у РЕД СОФТ есть **РЕД АДМ** (аналог Foreman/Spacewalk — централизованные обновления и конфиги, входит в корпоративную подписку); у Astra — возможности ALD Pro + собственный репозиторий.
- **ПО сторонних вендоров** (Р7, 1С, браузеры): дистрибутивы в локальном файловом репозитории, раскатка Ansible/GPO.

### 3.4. Итоговый набор инструментов (всё бесплатное, кроме ОС сервера)

`GLPI (инвентарь+helpdesk) + FOG (образы) + Ansible-pull (Linux-конфиги) + MDT/WDS+WSUS (Windows) + Git (IaC) + Zabbix (мониторинг)`. Время внедрения: 4–6 недель работы одного админа, дальше — 30–40% его времени на поддержку парка 400 мест.

## 4. VDI / тонкие клиенты: нужно ли?

**Доступные в РФ платформы:** Termidesk (ГК Astra, в реестре, лицензия ~21 000–30 000 ₽ за конкурентное подключение на 36 мес. — softmagazin/zvk.ru), Basis.WorkPlace, VeiL VDI. VMware Horizon и Citrix ушли.

**Оценка при одном админе:**

| Сценарий | Целесообразность |
|---|---|
| Колл-центр 60 мест на VDI (Termidesk) | **Сомнительно.** Нужны: кластер гипервизоров (2–3 сервера ~1,5–2,5 млн ₽), СХД или локальные NVMe, лицензии VDI (60 конкурентных × ~25 000 ≈ 1,5 млн ₽), тонкие клиенты (~20 000–30 000 × 60 ≈ 1,5 млн ₽), компетенции. Итого ~5–6 млн ₽ против ~2,5 млн ₽ за mini-PC + киоск-Linux. Плюс единая точка отказа и нагрузка на админа. VDI окупается на 150–200+ однотипных мест или при жёстких требованиях ИБ (ноль данных на АРМ) |
| Бухгалтерия на VDI | Нет: 30 мест, КриптоПро/токены/банк-клиенты через проброс — боль для админа. Локальные Windows-машины проще |
| Терминальный доступ (не VDI) к 1С | **Да** — уже фактически используется: 1С в клиент-серверном режиме + тонкий/веб-клиент покрывает «терминальный» сценарий без VDI-платформы |

**Вердикт:** при 60 местах колл-центра VDI не нужен. Оптимум — **mini-PC с неубиваемым Linux-киоском** (образ восстанавливается за 10 минут через FOG, данные не хранятся локально). VDI пересматривать при росте колл-центра >150 мест или требованиях ИБ.

## 6. Ключевые рекомендации

1. **Форм-фактор — mini-PC (класс ThinkCentre Tiny / iRU mini) для всех десктопов**, включая колл-центр; моноблоки не закупать; tower — только для части разработчиков.
2. **Гибрид ОС 80/20 в пользу Linux**: Windows оставить бухгалтерии и выездным интеграторам; колл-центр и продажи — Linux (РЕД ОС — дешевле, Astra — если нужна сертификация/экосистема).
3. **Автоматизация**: GLPI + FOG + Ansible-pull + локальный WSUS + локальные репозитории. Это бесплатный стек, поднимаемый одним админом.
4. **VDI не внедрять** на текущем масштабе; колл-центр — на Linux-киосках с образным восстановлением.
5. **ЗИП 5–8%** устройств и «горячая замена» вместо ремонта — главный механизм SLA при одном админе.
6. Ноутбуки с официальной гарантией — **Huawei/Honor**; ThinkPad через параллельный импорт с расширенной гарантией продавца (DNS/Ситилинк).
